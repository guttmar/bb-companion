# Blood Bowl Companion

The Blood Bowl Companion is an offline-capable reference and roster-building app for Blood Bowl rulesets. Its vocabulary distinguishes the in-app reference from the external materials it is based on.

## Language

**Rules Reference**:
The in-app, searchable collection of Blood Bowl rules content for a particular ruleset.
_Avoid_: rules page, manual, rulebook

**Rule Section**:
The smallest independently addressable and searchable unit of Rules Reference content, taken from one coherent part of a source chapter.
_Avoid_: page, blob, chunk

**Rules Snapshot**:
A reviewed, versioned local state of the rules content used to populate one Rules Reference.
_Avoid_: live feed, current rules
